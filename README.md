# F1 Discord Bot

A Discord bot that provides Formula 1 information using Python and FastF1.

## Features & Usage

Use these commands in your Discord server:

- `f1-standings` – Shows the current driver standings.
- `f1-nextevent` – Shows the next upcoming F1 event.
- `f1-results` – Shows the latest race results.

The bot also has an automatic reminder system that periodically sends messages to a configured Discord channel (currently in testing).
